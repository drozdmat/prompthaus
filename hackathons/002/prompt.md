# 🗑️ Hackathon #002 – Thanks, I Hate It!

## Challenge Overview
Build an anti-recommendation system powered by embeddings and vector databases.  
Instead of finding the closest, most relevant results, your system should return the farthest, weirdest, or most irrelevant ones.  
Swap comfort-zone personalization for chaos, surprises, and discovery of things you would normally avoid.  

Experiment with “reverse RAG,” absurd matches, and breaking out of information bubbles.  

### 🎯 Core Requirements
- **Anti-Recommendations**: Intentionally search for the worst or least relevant results  
- **Embedding Experiments**: Use vector similarity (but maximize distance)  
- **Humor & Creativity**: The project should surprise, amuse, or spark the “thanks, I hate it” reaction  
- **Usability Twist**: Even “bad” recommendations should be presented in an engaging way  

### Feature Ideas
- **Ugliest Images**: Given a prompt, retrieve the most unattractive or far-off images  
- **Worst Recipes**: Input ingredients → system outputs a dish you’d never want to eat  
- **Anti-Tinder**: Match people with the least compatible personality embeddings  
- **Anti-Social Feed**: Show posts completely outside of your filter bubble  
- **Out-of-Bubble Explorer**: Surface trends you’d never normally see  
- **Noise Recommender**: Return the most random, irrelevant documents possible  
- **“Thanks I Hate It” Meme Generator**: Contrast user input with the farthest possible result for humor  

## 📅 Time Limit
4 hours

*Remember: the goal isn’t accuracy – it’s deliberate misalignment.*
