# 🧠 Hackathon #003 – Human ~~In~~ Out of the Loop

## Challenge Overview
Build a **feedback loop** where models generate, interpret, and improve their own images or other data **without any human input or feedback.**
Once the loop starts, you can’t touch it. No corrections, no ratings, no steering.
Just observe what emerges, maybe just add some constraints.

Create closed ecosystems that evolve through iteration, and self-evaluation.

### 🎯 Core Requirements
- **No Human Feedback**: Once launched, your loop must run autonomously
- **Self-Iteration**: Each output should influence the next one
- **Emergent Meaning**: Let it evolve into something unexpected
- **Documentation**: Capture the evolution, the loop itself is the goal

### Feature Ideas
- **Image-Critique-Image Loop**: Model generates → critiques visually → regenerates
- **Dream Chain**: Each frame builds on the last, forming a visual narrative
- **Visual Debugger**: Agent circles or marks errors before regenerating
- **Style Evolution**: Start with one image and let the agent mutate its style endlessly
- **Concept Drift Visualizer**: Watch a concept transform until it becomes unrecognizable
- **Diagram Thinker**: An AI that tries to “explain” something using only sketches and arrows
- **Closed Loop Composer**: Two agents exchanging and transforming each other’s outputs

## 📅 Time Limit
4 hours
